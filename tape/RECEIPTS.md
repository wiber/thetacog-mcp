# RECEIPTS — what is in this directory, and how to disprove it

This is the production receipt tape of the repo that ships this instrument. Every file under
`panels/` and `encircled/` is one commit's **drift receipt**.

## What a receipt IS

A receipt is a **deterministic, LLM-free function of a single commit**. On each commit the
walker reads the commit's declared INTENT (its message and the docs it touched) and its
REALITY (the code it changed), places both on a 144×144 ShortLex lattice, and renders where
they agree, where reality fired outside the declared lane, and by how much. No model is in
that path. Re-run it on the same sha and you get the same image — that is the whole point.

- `panels/<sha>.png` — 144×144, one pixel per lattice cell.
- `panels/<sha>-encircled.png`, `encircled/<sha>.png` — 576×576, the INTENT · REALITY · Δ
  triptych with the off-lane regions circled.

Filenames are commit shas. Nothing else is encoded in them, and the PNGs carry no text
chunks and no metadata — they are bitmaps, and you can verify that with any PNG chunk dumper.

## How to recompute one

```bash
npx -y thetacog-mcp@latest attest-demo
```

That runs the same walker on a worked example and prints the placement it derives. Point it at
your own repository and it produces your own tape; publishing that tape is what activates your
own baseline (see `REGISTRY.md`).

## The sufficiency contract — what this is NOT sufficient for

**WHERE a commit landed relative to what it declared is provable and re-runnable. WHETHER the
commit is bug-free is UNDECIDABLE (Rice, 1953), and nothing here claims it.** A green panel
means reality stayed inside the declared lane, not that the code is correct. A receipt places
work against a lane declared before it ran; it does not reconstruct the work.

The panels are `[maintainer-generated, stranger-recomputable]` — each is verifiable
individually against its sha. `series.ndjson` is `[maintainer-reported]` scheduler
telemetry (when the background loop ran, and why it skipped) — it is **not** the per-commit
measurement series, and no breach-rate or volatility figure should be computed from it.
