## Reach IS Verify at Four Substrate Layers

Ask the server for one cell: `GET /api/pmu/cell/:intentId/:i/:j`. One fetch, one record back. Now read that same cell out of an array in a browser tab. Now read it off the wire as text. Now read it off two cache lines on the chip. Four containers, four unrelated technologies, and every one of them performs the identical arithmetic on the identical operand — because **the address that names the data is the address that verifies it**.

That is the whole claim, and you can check it from outside the network before you take any of the rest on faith. The cortex did it first; silicon is the engineering inverse, four substrate layers deep.

**Layer 1 — silicon.** Two reads, 144 bits each — the agent's intended cell and the policy cell it lands on. XOR the two, then popcount the result. No loop, no branch, no lookup; a constant-depth circuit that settles inside a clock, and nothing at this layer can drift into a different computation than the one printed here. This is the zero-hop principle your cortex used to bind "cache invalidation" to "session store" inside the 20ms window: the firing that reaches it is the firing that recognizes it.\*

**Layer 2 — JS in-memory grid.** A `Uint8Array(144)` indexed by `grid[i*12+j]`. Same 144 bits. Same XOR. Same popcount. The browser tab and the silicon execute the same arithmetic on the same operand because the index `(i,j)` means the same thing in both containers. The translation cost is zero because there is no translation.

**Layer 3 — JSON on the wire.** `{"cells":{"i,j": ...}}`. Hash O(1) lookup. The wire payload's address arithmetic is the silicon's address arithmetic with text encoding wrapped around it; strip the encoding and the operand is identical.

**Layer 4 — API route.** `GET /api/pmu/cell/:intentId/:i/:j`. One HTTP fetch, O(1) on the server, returns the cell record. A buyer's curl from outside the network produces the same verdict the JS tab produces, because both end at the same coordinate read.

> \* *The arithmetic, for the reader who divides by the clock.* Each 144-bit payload fits inside one 64-byte cache line with room to spare. XOR-then-popcount is AC⁰ — constant depth, so combinational logic has no cycle count of its own; it settles before whichever clock edge samples it. On shipped consumer silicon it runs as two ordinary retired instructions, XOR then a population count, roughly 100 picoseconds of gate and pipeline delay against a clock period near 285 picoseconds at 3.5 GHz — inside the period, with room. Wired into address decode on dedicated silicon it would settle in the gate's own propagation delay with no instruction fetched at all; that is the apparatus this design aims at, not the chip on your desk today. Either realization leaves no loop for an adversary to redirect and no lookup for a bug to hide in.

**Twelve axes is the human-readability ceiling, not the algorithmic one.** The algorithm is N × N for any N — twelve is the A / B / C × {root,1,2,3} taxonomy a human reads in one glance, thirty-two is SOC2-depth compliance, two-hundred-fifty-six an actuarial cluster catalog — and recursion takes any of them to N² at the next level.

**The property the four layers share, named.** Each container exposes the cell at a constant-time path. *Nothing has to search for a cell.* A search can return the wrong thing, return late, or return nothing; an address cannot do any of those. That is what lets reach-IS-verify extend from a laptop to a fleet: the thing that would degrade at scale is the lookup, and there is no lookup.
